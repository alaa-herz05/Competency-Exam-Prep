Computer Fundamentals
أساسيات الحاسوب
★★★★★ Very High
💻
What is a Computer?
الشرح بالعربي الحاسوب هو جهاز إلكتروني يقبل البيانات (Input)، يعالجها وفق تعليمات (Processing)، يخزّنها (Storage)، ويُخرج معلومات مفيدة (Output).

A computer is an electronic device that accepts data, processes it according to stored instructions, stores results, and produces meaningful information as output.

Input → Processing → Storage → Output   (IPO Cycle)
📊
Data vs Information
الشرح بالعربي البيانات (Data): حقائق خام بدون معنى — مثل: 85، 90، 70. المعلومات (Information): بيانات مُعالَجة ذات معنى — مثل: متوسط الدرجات = 81.
📥 Data — البيانات
Raw, unprocessed facts with no meaning on their own.
Example: 85, 90, 70
📤 Information — المعلومات
Processed data that has context and meaning.
Example: Average score = 81.7
🔧
Computer System Components
الشرح بالعربي نظام الحاسوب يتكون من: المكونات المادية (Hardware)، البرامج (Software)، البيانات (Data)، المستخدمون (Users)، الإجراءات (Procedures).
🖥️ Hardware
Physical components: CPU, RAM, Keyboard, Mouse, Monitor, Printer
💿 Software
Programs & instructions: Windows, Linux, Chrome, MS Word
👤 Users & Data
People who use the system and the data they work with
⚡
Computer Characteristics
الشرح بالعربي مميزات الحاسوب: السرعة، الدقة، الأتمتة (العمل الآلي)، الموثوقية، سعة التخزين، والتنوع.
CharacteristicالخاصيةMeaning
SpeedالسرعةProcesses millions of instructions per second
AccuracyالدقةProduces correct results every time
AutomationالأتمتةWorks automatically after receiving instructions
ReliabilityالموثوقيةConsistent performance without errors
Storage Capacityسعة التخزينStores vast amounts of data permanently
VersatilityالتنوعCan perform a wide variety of tasks
⚡ Quick Review — المراجعة السريعة CPU = Processing  |  Keyboard = Input  |  Monitor = Output  |  SSD/HDD = Storage  |  Information = Processed Data

✅ Answer: CPU

✅ Answer: Automation

Hardware Fundamentals
أساسيات المكونات المادية
🧠
CPU — Central Processing Unit
الشرح بالعربي المعالج المركزي هو "دماغ" الحاسوب. يتكون من: ALU (وحدة الحساب والمنطق)، وحدة التحكم (CU)، السجلات (Registers)، وذاكرة الكاش (Cache).
⚙️ ALU
Arithmetic & Logic Unit — performs +, −, ×, ÷ and logical operations (AND, OR, NOT, comparisons)
🎛️ Control Unit
Controls and coordinates all hardware components, manages instruction execution
📌 Registers
Smallest & fastest storage inside the CPU — holds temporary values during processing
💾
Memory Hierarchy
الشرح بالعربي هرم الذاكرة (من الأسرع للأبطأ): السجلات → الكاش (L1, L2, L3) → RAM → التخزين الثانوي (SSD/HDD). كلما كانت الذاكرة أسرع، كانت سعتها أصغر وأغلى.
Registers (fastest) → Cache L1 → Cache L2 → Cache L3 → RAM → SSD → HDD (slowest)
🔵 RAM — الذاكرة المؤقتة
Volatile — loses data when power is off. Temporary working memory. Fast access for running programs.
🟡 ROM — الذاكرة الدائمة
Non-volatile — retains data without power. Stores firmware/BIOS. Read-only by CPU.
💿
Storage Devices
الشرح بالعربي HDD: مغناطيسي، أبطأ، أرخص. SSD: إلكتروني، أسرع، صامت. NVMe SSD أسرع من SATA SSD.
StorageSpeedTechnologyNotes
NVMe SSDFastestFlash + PCIeBest performance for OS & apps
SATA SSDFastFlash + SATASilent, no moving parts
HDDSlowMagnetic disksCheaper, larger capacity
🖱️
Input vs Output Devices
الشرح بالعربي أجهزة الإدخال: لوحة المفاتيح، الفأرة، الماسح الضوئي، الميكروفون. أجهزة الإخراج: الشاشة، الطابعة، السماعات، جهاز العرض.
📥 Input Devices
Keyboard, Mouse, Scanner, Microphone, Webcam, Barcode Reader
📤 Output Devices
Monitor, Printer, Speakers, Projector, Plotter
⚡ Exam Tips CPU = Brain | Cache = Fastest memory after Registers | SSD > HDD in speed | RAM = volatile (loses data) | ROM = non-volatile

✅ SSD

Software Fundamentals
أساسيات البرمجيات
💿
Types of Software
الشرح بالعربي البرمجيات نوعان: برامج النظام (تدير الحاسوب) وبرامج التطبيقات (تساعد المستخدم على إنجاز المهام).
🖥️ System Software
Manages computer hardware and resources.
Includes: Operating Systems, Device Drivers, Utility Programs, Firmware.
Examples: Windows, Linux, macOS
📱 Application Software
Helps users perform specific tasks.
Examples: Microsoft Word, Excel, Chrome, Photoshop, VLC, Games
🔄
Compiler vs Interpreter vs Assembler
الشرح بالعربي المُترجم (Compiler): يترجم البرنامج كاملاً دفعة واحدة — أسرع عند التشغيل. المُفسِّر (Interpreter): يترجم سطراً بسطر — أسهل في تتبع الأخطاء. المُجمِّع (Assembler): يحوّل لغة Assembly إلى لغة الآلة.
TranslatorHow it WorksSpeedDebugging
CompilerTranslates entire program at onceFaster at runtimeHarder
InterpreterTranslates line by lineSlowerEasier
AssemblerAssembly → Machine languageVery fastComplex
⚖️
Open Source vs Proprietary
الشرح بالعربي المصدر المفتوح: يمكن عرض الكود وتعديله (مثل Linux). المُغلق (Proprietary): مملوك لشركة والكود سري (مثل Windows، Adobe).
🔓 Open Source
Source code is public — users can view, modify, and distribute. Examples: Linux, Firefox, VLC, LibreOffice
🔒 Proprietary
Company owns code — closed source. Examples: Windows, macOS, Adobe Photoshop, Microsoft Office
🛡️
Utility Software & Firmware
الشرح بالعربي برامج الخدمة: تُحافظ على أداء الحاسوب (مضاد الفيروسات، النسخ الاحتياطي، ضغط الملفات). البرامج الثابتة (Firmware): برامج دائمة مخزّنة في ROM تتحكم في الأجهزة عند بدء التشغيل.
🔧 Utility Software
Antivirus, Backup tools, Disk Cleanup, Disk Defragmenter, File Compression (ZIP/WinRAR)
⚙️ Firmware
Stored in ROM/Flash memory. Controls hardware at startup. Example: BIOS/UEFI on motherboard
⚡ Exam Tips OS = System Software | Word = Application Software | Compiler = faster at runtime | Interpreter = easier to debug | Firmware stored in ROM/Flash

✅ Application Software

✅ Interpreter
4. Which translates the whole program at once?
✅ Compiler
5. Firmware is stored in?
✅ ROM / Flash Memory

Operating Systems
أنظمة التشغيل
🖥️
What is an Operating System?
الشرح بالعربي نظام التشغيل هو برنامج نظام يدير موارد الحاسوب المادية والبرمجية ويوفر خدمات للتطبيقات. هو الوسيط بين المستخدم والعتاد.

System software that manages hardware, software resources, and provides services for application programs. It acts as the bridge between users and hardware.

🔑 Main Functions Process Management · Memory Management · File Management · Device Management · Security Management · User Interface
⚙️
Kernel & Shell
الشرح بالعربي النواة (Kernel): القلب الحقيقي لنظام التشغيل — تتواصل مباشرةً مع العتاد. الغلاف (Shell): الواجهة بين المستخدم والنظام — إما CLI (سطر أوامر) أو GUI (رسومي).
🔮 Kernel
Core of the OS. Communicates directly with hardware. Controls CPU, memory, and devices. Always running in the background.
🖥️ Shell
Interface between user and OS.
CLI = Command Line (e.g., Terminal, CMD)
GUI = Graphical (e.g., Windows Desktop)
📋
Types of Operating Systems
الشرح بالعربي أنواع أنظمة التشغيل: Batch (دُفعي)، Time-Sharing (تقاسم وقت)، Multiuser (متعدد المستخدمين)، Multitasking (متعدد المهام)، Real-Time (زمن حقيقي)، Distributed (موزّع).
TypeالنوعDescription
Batch OSدُفعيProcesses jobs in batches without user interaction
Time-Sharing OSتقاسم الوقتMultiple users share CPU time simultaneously
Multiuser OSمتعدد المستخدمينMultiple users access the system at the same time
Multitasking OSمتعدد المهامRun multiple programs at the same time
Real-Time OS (RTOS)زمن حقيقيProcesses data as it arrives with no delay (e.g., medical, aviation)
Distributed OSموزّعManages a group of networked computers as one system
🧩
Virtual Memory & Multitasking
الشرح بالعربي الذاكرة الافتراضية: تستخدم جزءاً من القرص الصلب كذاكرة إضافية عندما تمتلئ RAM. أبطأ من RAM لكنها تمنع توقف النظام. تعدد المهام: تشغيل برامج متعددة في آنٍ واحد. تعدد المعالجات: استخدام أكثر من CPU/Core.
🔁 Multitasking
Running multiple programs seemingly at the same time on one CPU by switching rapidly between tasks
⚡ Multiprocessing
Using two or more CPUs/cores simultaneously to process tasks in parallel — true parallel execution
⚠️ Virtual MemoryUses part of HDD/SSD as extra RAM when RAM is full. It is slower than RAM. Prevents system crashes when memory is exhausted.
⚖️
Windows vs Linux
الشرح بالعربي Windows: سهل الاستخدام، تجاري، دعم ممتاز للبرامج. Linux: مفتوح المصدر، آمن، مستقر، شائع على الخوادم.
FeatureWindowsLinux
LicenseProprietary (paid)Open Source (free)
Ease of UseVery user-friendlyRequires more knowledge
SecurityMore targeted by malwareMore secure
Common UseDesktop, gaming, businessServers, development, embedded
⚡ Exam TipsOS = System Software | Kernel = core of OS | Virtual Memory uses DISK space | Linux = Open Source | Windows = Proprietary

Cyber Security & Malware
الأمن السيبراني والبرامج الخبيثة
🛡️
CIA Triad — ثالوث الأمن
الشرح بالعربي ثالوث أمن المعلومات: السرية (Confidentiality) — فقط المصرّح لهم يصلون للبيانات. النزاهة (Integrity) — البيانات دقيقة وغير مُعدَّلة. التوفر (Availability) — الخدمات والبيانات متاحة دائماً.
🔐 Confidentiality
Only authorized users can access data. Enforced by passwords, encryption, access controls.
✅ Integrity
Data remains accurate and unchanged. Enforced by hashing, checksums, digital signatures.
🟢 Availability
Data and services remain accessible when needed. Enforced by backups, redundancy, uptime monitoring.
🦠
Common Malware Types
الشرح بالعربي الفيروس: يحتاج ملف مضيف. الدودة: تنتشر بنفسها عبر الشبكة. حصان طروادة: يتنكّر كبرنامج شرعي. الفدية: يشفّر الملفات ويطلب فدية. برنامج التجسس: يراقب المستخدم خفية. برنامج الإعلانات: يعرض إعلانات غير مرغوبة.
Malwareالبرنامج الخبيثHow it Works
VirusفيروسAttaches to a host file — needs user action to spread
WormدودةSpreads automatically over networks — no host file needed
Trojanحصان طروادةDisguised as legitimate software — runs secretly when installed
Ransomwareبرنامج الفديةEncrypts files and demands payment for decryption key
Spywareبرنامج تجسسSecretly monitors user activity and sends data to attacker
Adwareبرنامج إعلاناتDisplays unwanted advertisements
Rootkitجذر خفيHides malicious software from the OS and antivirus
Keyloggerمسجّل لوحة مفاتيحRecords every keystroke — captures passwords
Botnetشبكة بوتGroup of infected devices controlled remotely by an attacker
⚔️
Common Attacks & Security Tools
الشرح بالعربي الهجمات الشائعة: التصيد الاحتيالي (Phishing)، القوة الغاشمة (Brute Force)، حقن SQL، هجمات DoS/DDoS. أدوات الحماية: الجدار الناري (Firewall)، برامج مكافحة الفيروسات، VPN، IDS/IPS.
💥 Common Attacks
  • Phishing — tricks users into revealing credentials
  • Brute Force — tries all password combinations
  • SQL Injection — malicious SQL into database queries
  • DoS/DDoS — floods server to deny service
  • XSS — injects scripts into web pages
🛡️ Security Tools
  • Firewall — filters incoming/outgoing traffic
  • Antivirus — detects & removes malware
  • IDS — detects attacks
  • IPS — detects AND blocks attacks
  • VPN — encrypts internet traffic
🔐
Authentication vs Authorization & Encryption
الشرح بالعربي المصادقة (Authentication): التحقق من الهوية "من أنت؟". التفويض (Authorization): تحديد الصلاحيات "ماذا يمكنك فعله؟". التشفير: تحويل البيانات لصورة غير مقروءة. الهاش: تحويل لقيمة ثابتة الطول ولا يمكن عكسه.
🔑 Authentication
Verifies identity — "Who are you?"
Methods: passwords, biometrics, MFA, tokens
🗝️ Authorization
Determines permissions — "What can you access?"
Methods: roles, access control lists
🔒 Encryption vs HashingEncryption: converts readable data into unreadable form using a key — can be reversed.  |  Hashing: creates a fixed-length value — cannot be reversed. Used for password storage.
🛡️ Security Best PracticesUse strong passwords · Enable MFA · Install antivirus · Update software regularly · Use firewalls · Perform regular backups · Avoid phishing emails
⚡ Exam Tips Virus = needs host file | Worm = spreads by itself | Trojan = pretends to be legitimate | Ransomware = encrypts files | Firewall = filters traffic | Best protection against ransomware = Regular Backup
🎯 Practice Questions

✅ Ransomware

✅ Firewall

✅ Regular Backup

Computer Networks
شبكات الحاسوب
🌐
Network Types & Topologies
الشرح بالعربي أنواع الشبكات: PAN (شخصية)، LAN (محلية)، MAN (مدنية)، WAN (واسعة النطاق). أشكال الشبكات: Bus، Star (الأكثر شيوعاً)، Ring، Mesh، Tree.
📡 Network Types
  • PAN — Personal Area Network (Bluetooth, ~10m)
  • LAN — Local Area Network (home, office)
  • MAN — Metropolitan Area Network (city-wide)
  • WAN — Wide Area Network (country/world — Internet)
🔀 Topologies
  • Bus — single cable, all devices share
  • Star ⭐ — all connect to central hub/switch (most common)
  • Ring — circular connection
  • Mesh — every device connected to every other
📦
Network Devices
الشرح بالعربي Hub: يُرسل لجميع الأجهزة. Switch: يُوجِّه باستخدام عناوين MAC. Router: يربط شبكات مختلفة باستخدام IP. Access Point: يوفر الاتصال اللاسلكي. Modem: يتصل بمزود الإنترنت.
DeviceالجهازHow it WorksUses
HubموزّعBroadcasts data to ALL devicesMAC address
SwitchمحوّلForwards data using MAC addressesMAC address
RouterموجّهConnects different networksIP address
Access Pointنقطة وصولProvides wireless (Wi-Fi) accessWi-Fi
ModemمودمConnects local network to ISP/InternetAnalog↔Digital
📚
OSI Model vs TCP/IP Model
الشرح بالعربي نموذج OSI: 7 طبقات (من الأسفل للأعلى): Physical → Data Link → Network → Transport → Session → Presentation → Application. نموذج TCP/IP: 4 طبقات: Network Access → Internet → Transport → Application.
🔵 OSI Model (7 Layers)
7. Application
6. Presentation
5. Session
4. Transport
3. Network
2. Data Link
1. Physical
🟡 TCP/IP Model (4 Layers)
4. Application
3. Transport
2. Internet
1. Network Access
📡
Common Protocols & IP Addressing
الشرح بالعربي البروتوكولات الشائعة: HTTP/HTTPS (ويب)، FTP (نقل ملفات)، SMTP/POP3/IMAP (بريد إلكتروني)، DNS (يترجم الأسماء لـ IP)، DHCP (يُعيّن IP تلقائياً). IPv4: 32 بت. IPv6: 128 بت.

Private IPv4 ranges: 10.x.x.x · 172.16–31.x.x · 192.168.x.x
⚡ Exam TipsSwitch = MAC | Router = IP | DNS = name to IP | DHCP = auto IP | HTTPS = encrypted HTTP | Star = most common topology

Cloud Computing & Emerging Technologies
الحوسبة السحابية والتقنيات الناشئة
☁️
Cloud Service Models
الشرح بالعربي نماذج الخدمة السحابية: IaaS (بنية تحتية كخدمة) — أجهزة افتراضية. PaaS (منصة كخدمة) — بيئة تطوير. SaaS (برنامج كخدمة) — برامج جاهزة عبر الإنترنت مثل Gmail.
🏗️ IaaS
Infrastructure as a Service
Virtual machines, storage, networking.
Examples: AWS EC2, Azure VMs, Google Compute
🛠️ PaaS
Platform as a Service
Development environment for building apps.
Examples: Google App Engine, Heroku, Azure App Service
📱 SaaS
Software as a Service
Complete software delivered over the Internet.
Examples: Gmail, Microsoft 365, Zoom, Dropbox
🏢
Cloud Deployment Models
الشرح بالعربي نماذج النشر السحابي: العامة (Public) — مشتركة بين الجميع. الخاصة (Private) — لمؤسسة واحدة. الهجينة (Hybrid) — مزيج من العامة والخاصة. المجتمعية (Community) — مشتركة بين مجموعة منظمات.
ModelDescriptionExample
Public CloudShared infrastructure, managed by providerAWS, Azure, GCP
Private CloudDedicated to one organizationOn-premises VMware
Hybrid CloudMix of public + privateAzure Hybrid
Community CloudShared by a group of organizationsGovernment cloud
🤖
AI, ML & Deep Learning
الشرح بالعربي الذكاء الاصطناعي (AI): يمكّن الحواسيب من أداء مهام تتطلب ذكاءً بشرياً. التعلم الآلي (ML): فرع من AI — يتعلم الحاسوب من البيانات دون برمجة صريحة. التعلم العميق (Deep Learning): يستخدم شبكات عصبية متعددة الطبقات للمشاكل المعقدة.
AI  ⊃  Machine Learning  ⊃  Deep Learning
🧠 AI
Enables computers to simulate human intelligence — reasoning, learning, decision-making
📊 Machine Learning
Computers learn from data without explicit programming. Subset of AI.
🔬 Deep Learning
Uses multi-layer neural networks — image recognition, speech, NLP
🌍
IoT, Big Data, Blockchain & Virtualization
الشرح بالعربي إنترنت الأشياء (IoT): يربط الأجهزة الذكية بالإنترنت. البيانات الضخمة (Big Data): مجموعات بيانات ضخمة جداً تُحلَّل لاكتشاف أنماط. Blockchain: دفتر أستاذ رقمي لامركزي. الافتراضية: تشغيل أجهزة افتراضية متعددة على جهاز واحد.
📡 IoT
Connects smart devices — sensors, cameras, watches, home appliances — to the Internet for data exchange. Example: smart thermostat, smartwatch
📊 Big Data
Extremely large datasets analyzed to discover hidden patterns and trends. Characterized by Volume, Velocity, Variety (3 Vs).
⛓️ Blockchain
Decentralized digital ledger — stores transactions securely in linked blocks. Immutable and transparent. Used in cryptocurrencies.
🖥️ Virtualization
Allows multiple virtual machines to run on a single physical computer, improving hardware utilization and resource efficiency.
⚡ Exam TipsSaaS = software | PaaS = platform | IaaS = infrastructure | ML is a subset of AI | IoT = smart devices | Blockchain = decentralized

✅ IaaS

Databases & SQL Fundamentals
قواعد البيانات وأساسيات SQL
🗄️
Database Concepts
الشرح بالعربي قاعدة البيانات: مجموعة منظّمة من البيانات المترابطة يمكن تخزينها وإدارتها واسترجاعها بكفاءة. DBMS: نظام إدارة قواعد البيانات — برنامج لإنشاء وإدارة قواعد البيانات (MySQL، Oracle، PostgreSQL).
📚 Database
An organized collection of related data that can be stored, managed, and retrieved efficiently.
⚙️ DBMS
Software to create and manage databases.
Examples: MySQL, SQL Server, Oracle, PostgreSQL
✅ Advantages of Using a DBMSReduced redundancy · Improved security · Data sharing · Backup & recovery · Data consistency
🔑
Keys & Normalization
الشرح بالعربي المفتاح الأساسي (Primary Key): يُعرِّف كل سجل بشكل فريد ولا يمكن أن يكون NULL. المفتاح الأجنبي (Foreign Key): يربط جداول مختلفة ببعضها. التطبيع (Normalization): تنظيم البيانات لتقليل التكرار وتحسين التكامل.
🔑 Primary Key
Uniquely identifies each record in a table. Cannot be NULL. Cannot be duplicate.
🔗 Foreign Key
Links two tables together. References the Primary Key of another table.
📐 Normalization Forms1NF: No repeating groups, atomic values.  |  2NF: 1NF + no partial dependencies.  |  3NF: 2NF + no transitive dependencies.
📝
SQL — CRUD Operations
الشرح بالعربي SQL: لغة الاستعلام الهيكلية — تُستخدم لإنشاء البيانات، استرجاعها، تحديثها وحذفها. CRUD: Create=INSERT، Read=SELECT، Update=UPDATE، Delete=DELETE.
CREATE → INSERT   |   READ → SELECT   |   UPDATE → UPDATE   |   DELETE → DELETE
SQL Examples SELECT * FROM Students WHERE age > 18;
INSERT INTO Students (name, age) VALUES ('Ali', 20);
UPDATE Students SET age = 21 WHERE name = 'Ali';
DELETE FROM Students WHERE name = 'Ali';
🔀
SQL Joins & Transactions
الشرح بالعربي INNER JOIN: يُرجع الصفوف المتطابقة فقط. LEFT JOIN: كل صفوف اليسار + المتطابقة. RIGHT JOIN: كل صفوف اليمين + المتطابقة. FULL JOIN: كل الصفوف. خصائص ACID: الذرية، الاتساق، العزل، المتانة.
JOIN TypeReturns
INNER JOINOnly matching rows from both tables
LEFT JOINAll rows from left table + matching from right
RIGHT JOINAll rows from right table + matching from left
FULL JOINAll rows from both tables
⚡ ACID PropertiesAtomicity — all or nothing. Consistency — valid state before/after. Isolation — transactions don't interfere. Durability — committed data persists.
⚡ Exam TipsPrimary Key = unique, NOT NULL | Foreign Key = creates relationships | SELECT = retrieve | INSERT = add | UPDATE = modify | DELETE = remove | INNER JOIN = matching rows only

Polymorphism — same name, different behavior
