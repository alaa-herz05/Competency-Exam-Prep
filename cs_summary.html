الأمن السيبراني والبرمجيات الخبيثة

▼
الفيروس (Virus)
برنامج خبيث يُلصق نفسه بملفات أخرى وينتشر معها. يحتاج إلى تدخل المستخدم لتشغيله (مثل فتح ملف مصاب).
الدودة (Worm)
تنتشر تلقائياً عبر الشبكة دون تدخل المستخدم، وتستنزف موارد الشبكة. الفرق الجوهري عن الفيروس: لا تحتاج ملفاً مضيفاً.
حصان طروادة (Trojan)
يتنكر كبرنامج مشروع وينفذ مهاماً ضارة خفية. لا يتكاثر ذاتياً ولكنه خطير جداً لفتحه باباً خلفياً للمهاجم.
برنامج الفدية (Ransomware)
يُشفّر ملفات الضحية ويطلب فدية مالية مقابل مفتاح فك التشفير. الحل الأفضل: نسخ احتياطي منتظم في موقع منفصل.
برنامج التجسس (Spyware)
يعمل خفيةً لجمع بيانات المستخدم مثل كلمات المرور وعادات التصفح وإرسالها للمهاجم.
الهندسة الاجتماعية
خداع المستخدم نفسياً لكشف معلومات سرية أو النقر على روابط خبيثة. الحماية: التوعية وعدم فتح المرفقات المشبوهة.
جدار الحماية (Firewall)
يراقب حركة البيانات الداخلة والخارجة ويحجب الاتصالات غير المصرح بها بناءً على قواعد مُحددة مسبقاً.
التحليل الاستدلالي (Heuristic)
آلية كشف الفيروسات الجديدة غير المعروفة بتحليل سلوك البرنامج بدلاً من مقارنته بتوقيعات معروفة فقط.
الـ Sandboxing
بيئة افتراضية معزولة لتشغيل البرامج المشبوهة وتحليلها دون المساس بالنظام الحقيقي.

الشبكات والإنترنت والبروتوكولات

▼
نموذج OSI (7 طبقات)
يقسم الاتصال إلى 7 طبقات: المادية → ربط البيانات → الشبكة → النقل → الجلسة → العرض → التطبيقات. كل طبقة لها مهمة محددة.
TCP مقابل IP
IP يحدد العنوان (وجهة الحزمة). TCP يضمن وصول البيانات بشكل كامل ومرتب. معاً يُشكّلان أساس الإنترنت.
HTTPS مقابل HTTP
HTTPS يضيف طبقة تشفير SSL/TLS فوق HTTP لحماية البيانات أثناء النقل. ضروري للمواقع التي تتعامل مع بيانات حساسة.
IPv6 مقابل IPv4
IPv6 يستخدم 128 بت (مقابل 32 في IPv4) مما يوفر عناوين لا حصر لها، ويدعم IPsec للأمان المدمج.
VLAN
تقسيم الشبكة الفيزيائية الواحدة لشبكات منطقية معزولة (مثل شبكة إدارة، شبكة طلاب). يحسن الأمان والأداء.
بروتوكول ARP
يربط عنوان IP بعنوان MAC الفيزيائي للجهاز. يمكن استغلاله في هجمات Man-in-the-Middle بإرسال رسائل ARP مزيفة.
DNS
نظام أسماء النطاقات: يترجم أسماء المواقع (google.com) إلى عناوين IP رقمية. يُعدّ دليل هاتف الإنترنت.
VPN
شبكة خاصة افتراضية تُنشئ نفقاً مشفراً عبر الإنترنت لضمان خصوصية الاتصال والوصول الآمن للشبكات البعيدة.
